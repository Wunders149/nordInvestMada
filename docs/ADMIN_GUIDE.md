# Guide d'utilisation de l'administration

Ce guide explique les actions principales de l'espace d'administration de Nord Invest Madagascar.

## 1. Se connecter

1. Ouvrir l'adresse `/admin/login.html`.
2. Saisir l'identifiant et le mot de passe administrateur.
3. Cliquer sur **Connexion**.

Après connexion, le tableau de bord affiche les messages, les devis et les abonnés récents.

## 2. Comprendre le menu

- **Tableau de bord** : vue générale et activité récente.
- **Messages** : consulter les demandes envoyées depuis le site et modifier leur statut.
- **Devis** : suivre les demandes de devis et leur avancement.
- **Newsletter** : consulter les abonnés.
- **Sections** : modifier les textes des différentes parties du site.
- **Équipe, Services, Projets, Produits, Blog** : ajouter, modifier, publier ou supprimer du contenu.
- **Galerie** : importer, remplacer, renommer ou supprimer des images.
- **Dossiers** : gérer les documents PDF disponibles sur le site.
- **Tarifs** : mettre à jour les prix et les options du calculateur.
- **Paramètres** : modifier les informations générales du site.
- **Journal** : consulter l'historique des actions effectuées.

## 3. Modifier ou ajouter du contenu

1. Choisir une rubrique dans le menu.
2. Cliquer sur **Ajouter** pour créer un élément ou ouvrir un élément existant pour le modifier.
3. Compléter les champs obligatoires.
4. Vérifier l'image, le texte et le statut de publication.
5. Enregistrer, puis ouvrir le **Site public** pour vérifier le résultat.

Pour une suppression, vérifier soigneusement l'élément sélectionné : cette action peut être définitive.

## 4. Gérer les demandes

Dans **Messages** ou **Devis**, utiliser la recherche et les filtres pour retrouver une demande. Ouvrir la ligne pour lire les détails, puis mettre à jour son statut après traitement.

## 5. Images et documents

- Utiliser une image nette et adaptée à l'emplacement prévu.
- Vérifier l'aperçu après un import ou un remplacement.
- Pour un dossier PDF, contrôler le nom du fichier et son aperçu avant publication.

## 6. Bonnes pratiques

- Enregistrer une modification à la fois et vérifier le site public.
- Ne pas partager ses identifiants administrateur.
- Se déconnecter après utilisation avec **Se déconnecter**.
- Utiliser le **Journal** en cas de doute sur une modification.
- Utiliser **Mode sombre** si nécessaire pour le confort de lecture.
